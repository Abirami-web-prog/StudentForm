# 🎓 Student Form

Student Form is a simple web application created to collect and manage student information using HTML, CSS, and JavaScript.

The project demonstrates basic form development and JavaScript-based interaction with user input.

---

## 🎯 Project Objective

The objective of this project is to practice creating web forms and handling user input using frontend web technologies.

---

## ✨ Features

- 📝 Student Information Form
- 👤 Student Data Entry
- ⌨️ User Input Handling
- 🔄 Interactive Form
- 📱 Responsive Interface
- 🎨 Simple and Clean Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
